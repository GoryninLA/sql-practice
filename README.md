# SQL Practice — PostgreSQL & ClickHouse

This repository contains my university assignments and practical projects focused on SQL, relational databases, analytical queries, and database performance optimization.

## Technologies

- **PostgreSQL** — relational database management and data analysis
- **ClickHouse** — column-oriented database for analytical workloads
- **DBeaver / pgAdmin** — database management tools

## Repository Contents

### PostgreSQL

| Work | Topics |
|---|---|
| Lab 01 | SELECT, filtering, sorting, CRUD operations |
| Lab 02 | JOIN, subqueries, CASE, COALESCE, CAST |
| Lab 03 | Aggregate functions, GROUP BY, HAVING |
| Lab 04 | Window functions, RANK, LAG, CTE, running totals |
| Lab 05 | EXPLAIN ANALYZE, indexes, query optimization |
| Practical Work 01 | Date analysis, geospatial data, JSONB, arrays, text analysis |

### ClickHouse

| Work | Topics |
|---|---|
| Practical Assignment 01 | MergeTree engines, partitioning, analytical queries, ReplacingMergeTree, SummingMergeTree |

## Skills Demonstrated

- Writing SQL queries of different complexity
- Joining and aggregating data from multiple tables
- Using subqueries and Common Table Expressions (CTEs)
- Applying window functions for analytical calculations
- Analyzing query execution plans with EXPLAIN ANALYZE
- Creating indexes and comparing query performance
- Working with JSONB, arrays, dates, and geospatial data
- Understanding ClickHouse MergeTree table engines and partitioning
